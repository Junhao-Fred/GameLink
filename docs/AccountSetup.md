# GameLink 本机账号原型

无需后台、网络或服务配置。账号只在注册时使用的设备上有效，邮箱作为本机账号名称，不发送验证码，也不验证邮箱归属。

- **Register**：输入邮箱、至少 8 位密码和确认密码，注册后自动登录。
- **Sign in**：输入本机已注册的邮箱和密码。
- **Profile → Account → Sign out**：退出登录；再次启动前保持退出状态。
- **Continue without an account**：进入原有访客模式，继续使用之前保存的资料。

同一台设备可以依次注册多个账号。每个账号使用独立的本地资料，重新登录后恢复该账号在这台设备上保存的内容。有效的本机登录状态会在应用重启后恢复。

账号记录和登录状态保存在系统 Keychain 中；密码使用随机盐和 PBKDF2-HMAC-SHA256（600,000 次迭代）处理后保存，不保存明文密码。Keychain 数据不通过 iCloud 同步。每个账号的资料文件以其 UUID 分目录，访客文件保持原路径。

这是本机演示功能，没有跨设备账号、密码找回、在线发布或其他玩家的实时数据。

验证步骤：注册 A 并保存资料，退出；注册 B，确认不会显示 A 的资料；退出并重新登录 A，确认资料仍在；重启应用检查登录恢复；输入错误密码检查提示；使用访客入口检查原有资料。
